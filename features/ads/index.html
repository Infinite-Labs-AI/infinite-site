What it does

Read evidence

Inspect available Meta spend, delivery, conversions, revenue, CTR, CPA, and ROAS without turning missing values into zero.

Prepare paused work

Create campaign, ad-set, creative, and ad proposals that land or remain paused before delivery.

Govern changes

Propose pauses, activations, and budget actions with a frozen payload, confirmation, hard policy checks, snapshots, and history.

Evidence

Performance windows, proposal status, pre-action state, policy result, provenance, and the action ledger make “created paused” different from “live and spending.”

Where the data comes from

  • Current Meta account reads where the workspace's supported data plane is available.
  • Infinite conversion and revenue evidence used beside ad delivery metrics.
  • Google Ads infrastructure for search structure, keywords, search terms, performance, pause, and enable operations.
  • Local analysis plus durable proposal and action-history records.

Review boundary

Every local-agent write proposal requires confirmation. Activation starts real spend and requires confirmation, but approval still cannot bypass unresolved budgets, hard caps, protected entities, the kill switch, or policy guards.

Limitations

The current desktop experience is Meta-first; Google Ads infrastructure does not imply matching UI coverage. Infinite does not promise automatic budget control or performance lift, and some workspace modes honestly report that live reads are unavailable.
