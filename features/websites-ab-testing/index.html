What exists

Public ideas tool

The no-signup generator produces landing-page CRO planning and conversion hypotheses for a page you already have.

CRO diagnosis

Retained analysis can inspect page content, funnel leaks, source differences, signal health, and ad-to-page message match where evidence exists.

Published-page runtime

Already-published recipe pages and custom-domain infrastructure remain available to their existing owners.

Evidence

The public evidence is the working A/B test ideas generator. It accepts an existing-page brief and returns hypotheses; it is not an experiment result.

What it does not do

The current tool does not create variants, split traffic, calculate significance, or roll out a winner. Retained publishing and custom-domain infrastructure is not a current builder promise.

Early-access connection guide

Connect your landing-page project

The Infinite Websites integration connects the Vercel project that hosts your marketing website. This setup is available in the early-access desktop build; it does not enable a live experiment by itself.

  1. Connect GitHub. In Infinite desktop, open Settings → Connections → GitHub · Website. Install Infinite Websites for the repository behind your landing pages and select that repository. You do not need to grant access to your SaaS application repository.
  2. Connect Vercel. From the connected website row, choose Connect Vercel. Select the Vercel team and grant access only to the matching landing-page project. Return to Infinite and select that project.
  3. Verify the match. The GitHub repository, production branch, project folder and verified production hostname must agree. Initial support is static HTML on Vercel, using the Other framework preset.
  4. Check analytics and setup. Infinite reuses the existing analytics setup for your website. If none is configured, it provides the infinite analytics command to run from your website repository. Hosting connected means access is verified; preview, tracking and experiment setup are separate checks.

What access does this grant?

The Vercel integration requests read access to its installation and selected project, plus read/write access to deployments for website previews. Deployment protection stays in place. The connection flow does not change environment variables or start a test.

If the connection does not verify

Check that both connections refer to the same repository and production domain, and that your Vercel account can authorize the project. A redirect domain, preview-only domain, unsupported framework or missing project permission cannot be used. GitHub access alone may not be sufficient for Vercel to build a contributor’s commit.

Disconnect or get help

Manage the website connection from Infinite’s Connections page. You can also revoke the integration in your Vercel team’s Integrations settings and remove repository access in GitHub. For help, contact support@ultima.inc. See our Privacy Policy and Terms.
